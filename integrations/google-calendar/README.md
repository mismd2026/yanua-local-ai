# Googleカレンダーから受付コードを発行する（Apps Script）

会議室と社外のゲストを入れた予定に、ゲストごとのインビテーションコードを発行して、ゲストにメールで送ります。
予定を作る・会議室を選ぶという、ふだんの手順の続きでコードが出せます。

```
Googleカレンダー（予定・会議室・社外ゲスト）
   │ アドオンの「発行」ボタン、または1時間ごとの自動発行
   ├──→ ゲストにメール（日時・会議室・担当・コード）
   └──→ スプレッドシート（コードのハッシュだけ）
             │ CSVで書き出して、Yanua のマシンへ
             ▼
        python -m yanua visit-import visits.csv → 受付でコードを入力 → 予定の表示・入館票・担当者へお知らせ
```

Yanua は社外に通信しない作りなので、Googleとは直接つなぎません。シートのCSVで受け渡します。

## 入れ方

1. **スプレッドシートを作る**：空のシートを作り、URLの `/d/` と `/edit` の間（ID）を控えます。共有は総務など、受付を管理する人だけにします。
2. **Apps Script のプロジェクトを作る**：[script.google.com](https://script.google.com) で新しいプロジェクトを作り、`Code.gs` の中身を貼ります。
3. **マニフェストを貼る**：「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにし、`appsscript.json` の中身を貼ります（Calendar API の拡張サービスも、これで有効になります）。
4. **スクリプトのプロパティ**（「プロジェクトの設定」の下）：

   | プロパティ | 内容 |
   |---|---|
   | `SHEET_ID` | 1. のID（必須） |
   | `INTERNAL_DOMAINS` | 社内のメールドメイン（カンマ区切り）。省略時は自分のメールアドレスのドメイン |
   | `HOST_CONTACT` | ゲストに見せてよい自分の連絡先の既定値（例：内線4100） |

5. **試しに入れる**：「デプロイ」→「デプロイをテスト」→ Google Workspace アドオン →「インストール」。カレンダーで予定を開くと、右側にアイコンが出ます。初回は権限の確認が出ます。
6. **会社全体で使う**：管理者が、Google Workspace Marketplace で社内向け（非公開）に公開します。

## 使い方

- **アドオン**：会議室と社外のゲストを入れて予定を保存 → 予定を開いて右側のアイコン → ゲストごとに会社名・お名前を確かめて「コードを発行してメールで送る」。
- **自動発行**：アドオンのホーム画面で「自動発行を有効にする」。1時間ごとに、自分が主催で会議室が入っている予定の社外ゲストに発行します（会社名はメールのドメイン、お名前はカレンダーの表示名）。
- **リスケ・取り消し**：日時や会議室を変えたら「日時・会議室の変更をシートに反映」を押します（自動発行が有効なら1時間ごとに反映）。コードはそのまま使えます。予定の削除やゲストの削除では、シートの行が「取消」になり、受付でそのコードは使えなくなります。
- **Yanua への取り込み**：シートを「ファイル」→「ダウンロード」→「CSV」で保存し、Yanua のマシンで取り込みます。何度取り込んでも重なりません（同じコードの予定は更新）。

  ```bash
  python -m yanua visit-import visits.csv
  ```

  決まった時刻に取り込むなら、Google ドライブ（パソコン版）でシートの書き出し先を同期し、タスクスケジューラや cron で `visit-import` を流します。

## 守りのしくみ

- コードはゲストへのメールにだけ載せます。シートにはハッシュだけを残すので、シートを見てもコードはわかりません。
- コードは、紛らわしい文字（0とO、1とIなど）を除いた8文字です。ハッシュの作り方は Yanua（`yanua/visits.py`）とそろえていて、`test_addon.js` で同じになることを確かめています。
- 担当者は、予定の主催者のメールアドレスを人事データ（在籍中の人）と照合して決めます。人事データにメールアドレスの列が要ります（`demo/company/hr/mapping_sample.json` の `email`）。退職者が主催の予定は取り込みません。
- 辞退したゲストと社内の参加者には発行しません。終日の予定も対象外です。

## 制限

- 会議室（リソース）は Google Workspace の機能です。個人の Gmail では会議室の代わりに予定の「場所」を使います（自動発行は会議室のある予定だけが対象）。
- メールの送信数には、Apps Script の1日あたりの上限があります（個人のアカウントは少なめ）。
- Microsoft 365（Outlook）の予定表も、同じ形（ハッシュをCSVで渡す）で対応できます。今はGoogleだけです。
