# 受付の会話の流れ用データ（架空）

| ファイル | 内容 |
|---|---|
| `routes.csv` | 用件の種類ごとの、引き継ぎ先（`route`）・優先度・お客様への返事。会社ごとに書き換える |
| `visits.csv` | 来訪の予定。`date` が当日で、会社名か担当者が一致すると、お約束ありとして会議室を案内する。`host_employee_no` は人事データの社員番号 |

- 答えに使うのは `demo/company/public/`（`access: 社外公開`）の文書だけです。
- 訪ね先の社員は人事データ（在籍中の人）から探しますが、所属・連絡先・在籍しているかどうかは、お客様には伝えません。
- デモの来訪予定は 2026-11-16 です。`--today 2026-11-16` を付けると、その日として動きます（`--demo` では自動）。
