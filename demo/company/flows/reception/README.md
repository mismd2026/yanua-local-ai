# 受付の会話の流れ用データ（架空）

| ファイル | 内容 |
|---|---|
| `routes.csv` | 用件の種類ごとの、引き継ぎ先（`route`）・優先度・お客様への返事。会社ごとに書き換える |
| `calendar_export_sample.csv` | Googleカレンダーのアドオンが書き出すシートの例（コードはハッシュだけ）。`visit-import` で取り込める。デモのコードは `QW8E-RT5Y`（2026-11-16）と `ZK3N-8PXD`（取消） |
| `visits.csv` | デモ用の来訪予定。`visit-import` で登録する（`reception --demo` では自動）。`code` はデモ用に決めたインビテーションコードで、ふだんは空にして自動で作る |

- 答えに使うのは `demo/company/public/`（`access: 社外公開`）の文書だけです。
- 訪ね先の社員は人事データ（在籍中の人）から探しますが、所属・連絡先・在籍しているかどうかは、お客様には伝えません。
  インビテーションコードで受け付けたときだけ、担当者が登録した連絡先（`host_contact`）を表示します。
- デモの来訪予定は 2026-11-16 です。`--demo` ではその日として動きます。
