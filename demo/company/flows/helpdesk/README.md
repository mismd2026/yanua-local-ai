# ヘルプデスクの会話の流れ用データ（架空）

| ファイル | 内容 |
|---|---|
| `kb.csv` | 一般的な切り分けの手順。`clarify` は聞き返す内容、`escalate_when` は情報システム部に引き継ぐ条件（「常に」で始まると、案内のあと必ず引き継ぐ） |
| `accounts.csv` | ログインアカウントの一覧。`personal` は個人用（`employee_no` で人事データとつなぐ）、`shared` は代表アカウント |
| `outages.csv` | 発生中の障害。`active` が `yes` の行だけを使う。`location` が `全社` なら場所を問わず該当 |

会社ごとの決まり（プリンターの名前、問い合わせ先の内線など）は、`demo/company/docs/` の社内文書から出典つきで答えます。
ここの手順は、社内文書に答えがないときの補いです。
