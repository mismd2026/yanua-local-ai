# デモ用の社内資料（架空の会社）

社内AIの動作確認と評価に使う資料です。会社・人物・システム名・数値はすべて架空で、実在の会社とは関係ありません。

## 会社の設定

- 社名：株式会社ヤヌアデモ商事（架空）
- 事業：オフィス用品の卸売
- 社員数：約120名
- 部署：総務部、人事部、経理部、情報システム部、営業部

## 資料の置き方

`docs/` に1文書1ファイルのMarkdownで置きます。先頭に次の項目を書きます。

| 項目 | 内容 |
|---|---|
| id | 文書ID。評価用の質問セットから出典として参照する |
| title | 文書名 |
| access | 閲覧できる部署。`全社` か、部署名をカンマ区切りで書く |
| owner | 管理する部署 |
| updated | 最終更新日 |

`access` が `全社` 以外の文書は、その部署の社員の質問にだけ使います。それ以外の部署の質問では、回答にも出典にも出してはいけません。
