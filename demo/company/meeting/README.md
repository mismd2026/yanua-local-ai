# 会議の録画のデモ（架空）

| ファイル | 内容 |
|---|---|
| `demo_zoom.mp4` | Zoom風の会議の録画（44秒・声なし）。前半はスピーカービュー、後半はギャラリービュー（発言中の枠が緑） |
| `demo_zoom_segments.json` | 台本どおりの発言と時刻。`meeting --segments` で文字起こしの代わりに使える。`expected` は正しい話し手 |
| `templates/議事録.docx` | 議事録の様式。差し込む位置を `{{...}}` で書いてある |
| `fakeui.py` | Zoom・Teams・Meet 風の画面を作る部品（テストでも使う） |
| `make_demo.py` | 上の動画を作り直す。`--voicevox` で、この端末の VOICEVOX（http://127.0.0.1:50021）を使って声を入れる |
| `make_template.py` | 議事録の様式を作り直す |

画面は名前の表示の位置と強調の枠の色だけを似せたもので、各社の本物の画面ではありません。人物・会社・内容はすべて架空です。
本物の録画で確かめるときは、自分のアカウント同士でテスト会議を開き、数分録画したものを使ってください。
