# 経費精算の手順

## 申請の流れ

1. 経費精算システム「ケイヒくん」にログインします。
2. 「新規申請」から、日付・金額・用途を入力します。
3. 領収書をスマートフォンで撮影して添付します。紙の領収書は原本を提出する必要はありませんが、申請から1か月は手元に保管してください。
4. 上長の承認を受けると、経理部の確認に回ります。

## 締め日と支払日

- 毎月末で締め、翌月の第5営業日までに申請してください。
- 承認された経費は、翌月25日の給与と一緒に振り込みます。

## 承認のルール

- 1件3万円未満は上長（課長）の承認で済みます。
- 1件3万円以上は、部長の承認も必要です。

## 交通費

- 電車・バスの交通費は、経路検索の結果の画面を添付してください。
- タクシーは、終電後の移動や重い荷物の運搬など、理由がある場合だけ使えます。理由を用途欄に書いてください。
