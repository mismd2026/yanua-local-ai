# 月次決算の手順（経理部向け）

## スケジュール

| 時期 | 作業 |
|---|---|
| 月末 | 締め日。当月分の請求書・経費の受付を締める |
| 第3営業日 | 仮締め。売上・仕入・経費を集計する |
| 第5営業日 | 確定。部門別の損益を役員会へ報告する |

## 主な作業

- 売掛金は、取引先からの入金と請求書を照合します。差異があれば営業部の担当者に確認します。
- 経費はケイヒくんから出力したデータを会計システムに取り込みます。
- 仮締めの後に見つかった修正は、経理部長の承認を受けてから反映します。

## 確認者

- 月次の数値は、作成者とは別の担当者が確認してから確定します。
