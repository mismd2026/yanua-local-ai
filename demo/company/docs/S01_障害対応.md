# 障害対応の手順（情報システム部向け）

## 障害のレベル

| レベル | 影響 | 例 |
|---|---|---|
| レベル1 | 全社の業務が止まる | メール・ファイルサーバー・ネットワークの停止 |
| レベル2 | 一部の部署の業務が止まる | 経理の会計システムの停止 |
| レベル3 | 個人の業務に影響する | 1台のPCの故障 |

## レベル1のとき

1. 気づいてから15分以内に、情報システム部長へ電話で連絡します。
2. 社内ポータルの障害通知掲示板に、障害の内容と影響を掲載します。
3. 復旧するまで、30分ごとに状況を掲示板で更新します。
4. 復旧したら、掲示板に復旧を掲載します。

## 報告書

- レベル1とレベル2の障害は、復旧から3営業日以内に障害報告書を作ります。
- 報告書には、原因・影響・対応の経過・再発防止策を書きます。
