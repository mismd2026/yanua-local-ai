# 人事評価の運用手順（人事部向け）

## 評価の時期

- 評価は年2回、4月と10月に行います。

## 進め方

1. 本人が自己評価を入力します。
2. 課長が一次評価をします。
3. 部長が二次評価をします。
4. 人事部が全社の評価を集計し、部署間のばらつきを確認します。

- 評価の入力期限は、評価月の20日です。
- 評価は S・A・B・C・D の5段階です。B が標準です。
- S と D の評価には、部長のコメントが必須です。

## 評価面談

- 評価の結果は、一次評価者が本人と面談して伝えます。面談は30分以上取ってください。
- 面談の記録は、人事システムに面談日から7日以内に入力してください。

## 取り扱い

- 評価の結果は秘密情報です。本人と評価者、人事部以外に見せてはいけません。
