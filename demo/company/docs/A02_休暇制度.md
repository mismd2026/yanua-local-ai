# 休暇制度

## 年次有給休暇

- 入社から6か月たった時点で10日付与します。その後は1年ごとに勤続年数に応じて増えます。
- 半日単位（午前休・午後休）でも取れます。
- 申請はハルカ勤怠から、取得日の3営業日前までに出してください。急な体調不良などの場合は、当日の始業前に上長へ連絡し、後から申請してください。
- 使わなかった有給休暇は、翌年度まで繰り越せます。

## 夏季休暇

- 7月から9月の間に3日取れます。連続して取っても、分けて取っても構いません。

## 慶弔休暇

| 事由 | 日数 |
|---|---|
| 本人の結婚 | 5日 |
| 配偶者の出産 | 2日 |
| 父母・配偶者・子の死亡 | 5日 |
| 祖父母・兄弟姉妹の死亡 | 3日 |

慶弔休暇はハルカ勤怠の「特別休暇」から申請します。
