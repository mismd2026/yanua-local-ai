# 就業規則（抜粋）

## 勤務時間

- 標準の勤務時間は 9:00〜17:30、休憩は 12:00〜13:00 の1時間です。
- フレックスタイム制を使えます。コアタイムは 10:00〜15:00 です。
- 始業・終業の時刻は勤怠システム「ハルカ勤怠」に毎日打刻します。打刻を忘れた日は、翌営業日までに修正申請を出してください。

## 在宅勤務

- 在宅勤務は週3日まで使えます。
- 前日の17:00までに、ハルカ勤怠から在宅勤務の申請を出し、上長の承認を受けてください。
- 在宅勤務の日も、コアタイム中はチャットで連絡が取れる状態にしてください。

## 休日

- 土曜・日曜・祝日、年末年始（12月29日〜1月3日）は休日です。
- 休日に出勤した場合は、4週間以内に振替休日を取ってください。

## 時間外労働

- 残業は事前に上長へ申請し、承認を受けてから行います。
- 月の時間外労働が30時間を超えそうな場合は、上長が人事部へ相談します。
