# 複合機（プリンター）の使い方

## 印刷のしかた

1. PCから「HD-PRINT」というプリンターを選んで印刷します。
2. 複合機の読み取り部に社員証をかざすと、自分の印刷物が出てきます。
3. 印刷したまま12時間取り出さなかった印刷物は、自動で消えます。

- 初期設定は白黒・両面です。カラーで印刷するときは、印刷の画面で切り替えてください。
- カラー印刷に申請はいりませんが、部署ごとの枚数を毎月集計しています。

## 紙が詰まったとき

- 複合機の画面に、詰まっている場所が表示されます。表示どおりに扉を開けて紙を取り除いてください。
- 直らないときは、総務部（内線2200）へ連絡してください。

## トナーと用紙

- トナーの交換は総務部が行います。画面に「トナー残量わずか」と出たら、総務部へ連絡してください。
- 用紙は各フロアの備品棚にあります。

## スキャン

- スキャンしたデータは、自分の会社のメールアドレスにだけ送れます。社外のアドレスには送れません。
