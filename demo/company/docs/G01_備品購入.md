# 備品の購入手順（総務部向け）

## 承認

- 1件1万円未満の備品は、総務部の課長が承認します。
- 1件1万円以上の備品は、総務部長の承認も必要です。

## 購入のしかた

- 購入は購買システムから、登録済みの取引先に発注します。
- 登録されていない取引先から買う場合は、事前に見積書を2社以上から取ってください。

## 固定資産

- 1件10万円以上の備品は固定資産になります。届いたら資産番号のシールを貼り、固定資産台帳に登録してください。
- 台帳の内容は、年1回（3月）に現物と照合します。
