Yanua の費用：自前・AWS・GCP・Azure・Claude API

人数・稼働率・トークン数を変えると、初期費用と毎月の費用がその場で変わります。単価は 2026年11月に調べた東京リージョンの定価（オンデマンド）です。下の表で書き換えられます。

使い方

χ は1人が1日に答えを作っている時間。100%＝就業時間中ずっと全員が答えを作っている、いちばん厳しい見方。GPU はこの混む時間に合わせて用意し、夜や休日も止めずに1か月730時間（24時間×365日÷12）で計算します。

共通の前提

Yanua 本体は画面・権限・人の台帳・監査ログ・承認の流れ・DB・社内文書の検索を動かす、GPU のいらないサーバー。どの方式にも必要です（値は仮）。

自前は「初期費用＋毎月の支払い（電気・保守）× 月数」。クラウドと API は初期費用なし。どの方式にも Yanua 本体のサーバー（GPU なし）を含みます。ラック代・回線・人件費は入っていません。

方式ごとの内訳（単価は書き換えられます）

方式GPU 1枚の同時数単価台数初期費用毎月1年

単価：自前は GPU 1枚の購入価格（円）、クラウドは GPU 1枚の時間単価（ドル。国内は円）、API は入力／出力 100万トークンあたりのドル。同時数は vLLM・Qwen2.5-7B の公開測定（L40S 32件・H100 64件）。L4 の 12件は仮の値で、実測で直してください。GCP の H100 1枚の型はスポットか Flex-start でしか作れないため、常時使うなら 8枚の型（a3-highgpu-8g）で見積もり直してください。
