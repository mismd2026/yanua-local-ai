# 費用計算ツール（参考資料）

Yanua を動かすのにかかる費用を、方式ごとに比べるためのツールです。[index.html](index.html) をブラウザで開くだけで動きます（サーバーは要りません）。

## 何を出すか
社員数・使う人の割合・稼働率・1問のトークン数から、次の方式ごとに、初期費用、毎月・1年・指定した年数の総額、損益分岐点（自前がクラウドや API より安くなるまでの期間）を出します。

- 自前（L40S・H100）
- AWS・GCP・Azure
- 国内クラウド
- Claude API

どの方式にも、GPU のいらない Yanua 本体のサーバー（画面・権限・人の台帳・監査ログ・DB・社内文書の検索）を含めます。

## 前提
- **単価**：2026年11月に調べた、東京リージョンのオンデマンドの定価です。為替は 1ドル＝155円です。
- **GPU 1枚の同時数**：vLLM・Qwen2.5-7B の公開測定から取りました（L40S 32件・H100 64件）。L4 の 12件と、Yanua 本体サーバーの値は仮です。
- 単価・同時数・前提は、どれも画面で書き換えられます。書き換えた値は、そのブラウザの中にだけ残ります（localStorage。どこにも送りません）。「前提を最初の値に戻す」で最初の値に戻ります。
- **稼働率**＝χ／就業時間です。χ は、1人が1日に答えを作っている時間です。
- **GPU の数**はいちばん混む時間に合わせて用意し、24時間・月730時間（24時間×365日÷12）動かす前提で計算します。

## 入っていないもの
ラック代・回線・人件費・ソフトの保守は入っていません。

## 社外に出られない環境で開くとき
見出しの文字は Google Fonts（fonts.googleapis.com）を読みに行きます。社外に出られない環境では読めないので、端末にある文字で表示されます。計算には影響しません。ほかに外へ通信するものはありません。

## これからすること
同時数は、Yanua の実際の使い方で測り直して直します（課題表 K-013）。
