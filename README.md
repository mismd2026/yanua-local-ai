# yanua-local-ai

社内の資料に答える、外部にデータを出さないローカルAIです。

社内規程・マニュアル・ナレッジを読み込み、社員の質問に出典つきで答えます。LLMは Ollama で社内のマシン上に置き、質問・資料・回答を社外に送りません。

前身は [ai-callcenter-ollama](https://github.com/mismd2026/ai-callcenter-ollama)（電話で応答するAI）です。電話向けの機能を外し、社内向けの質問応答に絞って作り直しています。

## 目指す動き

- **出典つきで答える。** 回答に、元になった文書名と該当箇所を付けます。
- **資料にないことは答えない。** 根拠が見つからない質問には、推測せずに「わかりません」と答えます。
- **部署ごとの閲覧権限を守る。** 見る権限のない部署の資料は、検索の段階で除きます。
- **社外に通信しない。** 外部ネットワークを遮断した状態でも、すべての機能が動くようにします。

## 構成

```
yanua/          本体（取り込み・権限つき検索）
demo/company/   デモ用の架空の会社の社内資料（20文書・5部署）
eval/           評価用の質問セット（70問）と採点スクリプト
tests/          テスト
```

## 使い方

Python 3.11 以上の標準ライブラリだけで動きます。

```bash
# 資料を取り込む。2回目以降は、変わった文書だけを反映し、なくなった文書は消す
python -m yanua ingest demo/company/docs

# 部署の権限つきで検索する
python -m yanua search "在宅勤務は週に何日までできますか？" --department 営業部

# 取り込んだ文書と、閲覧できる部署の一覧
python -m yanua docs

# Ollamaで出典つきの回答を作る（Ollamaが動いていること）
python -m yanua ask "在宅勤務は週に何日までできますか？" --department 営業部 --model qwen2.5:3b

# HTTP API を起動する（POST /ask、GET /health）
python -m yanua serve --model qwen2.5:3b --port 8000
```

### 回答

- 検索で見つかった本文だけを番号つきでLLMに渡し、その範囲だけで答えさせます。回答の [1] などの番号から出典を決めます。
- 資料に根拠がないときは、推測せずに「わかりません」と答え、問い合わせを案内します。
- LLMに渡すのは、質問者が見られる文書の本文だけです。LLMがどう答えても、見られない文書の内容は回答に出てきません。

取り込んだ内容は `data/index.db`（SQLite）に保存します。

### 取り込み

- 1文書1ファイルのMarkdownを、見出しごとに分けて登録します。
- ファイルの内容のハッシュを比べ、変わった文書だけを登録し直します。
- 先頭に `access`（閲覧できる部署）がない文書は取り込みません。書き忘れた文書が全員に見えてしまうのを防ぐためです。

### 部署別の権限

- 検索の前に、質問者の部署が見られる文書だけをSQLで取り出し、その中だけを検索します。
- LLMへの指示や、検索した後での除外には頼りません。見られない文書は、検索の候補にも入りません。

### 検索

- BM25で検索します。日本語は2文字ずつの組（バイグラム）で比べるので、辞書やモデルのダウンロードはいりません。
- 「夏休み」と「夏季休暇」のような言い換えには弱いため、埋め込みベクトルでの検索を後で組み合わせる予定です。

## 評価

```bash
pip install -r requirements-dev.txt
python eval/run_eval.py --check      # 質問セットと資料の整合チェック
python eval/retrieval_eval.py        # 検索だけの評価（LLMなし）
python -m pytest -q                  # テスト
```

検索だけの評価の結果（質問70問）：

| 上位の件数 | 期待する文書が入った割合 | 答えの材料が入った割合 | 権限違反 |
|---|---|---|---|
| 1件 | 89.3% | 87.5% | 0件 |
| 3件 | 94.6% | 94.6% | 0件 |
| 5件 | 96.4% | 98.2% | 0件 |

APIができたら、`run_eval.py --endpoint` で回答まで含めて採点します。詳しくは [eval/README.md](eval/README.md) を見てください。
